0. Seguir las instrucciones de https://github.github.com/spec-kit/installation.html 

1. Instalar Python. https://www.python.org/downloads/release/python-3146/

2. Instalar UV (package & project manager de python escrito en rust) https://docs.astral.sh/uv/

3. CMD: uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@v0.10.3

4. Instalar el gemini CLI o el que usen. https://geminicli.com/

5. Iniciar sesión en gemini. CMD: gemini
5.1. Seguir los pasos, iniciar sesión con google, verificar con el teléfono, etc.
